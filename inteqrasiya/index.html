İnteqrasiya haqqında suallar

İnteqrasiya nə qədər çəkir?

Adətən 1⁠–⁠3 iş günü; lazım olsa, tam inteqrasiyanı komandamız edir.

1C ilə işləyirmi?

Bəli, hazır 1C nümunəsi var. HTTP dəstəkləyən istənilən sistem qoşulur.

API olmadan işləmək olarmı?

Bəli, Excel/CSV yükləmə və çıxarış dərhal hazırdır.

Hansı nömrədən zəng gedir?

Sizin mövcud SIP və ya ATS nömrənizdən.
