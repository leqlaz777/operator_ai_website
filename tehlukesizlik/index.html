Sizin serverinizdə

Windows Server, IIS və PostgreSQL — səs yazıları və siyahılar yalnız sizdə qalır.

AI hesabı sizindir

Açarlar sizdədir; canlı səs birbaşa AI provayderinə gedir, arada saxlanmır.

Rollar və giriş

Admin/operator rolları, heşlənmiş şifrələr və yalnız icazəli dinləmə.

Audit jurnalı

«Əvvəl → sonra» dəyişiklik tarixçəsi və uğursuz girişlərin IP qeydi.

İmzalı API & Webhook

SHA-256 açar heşi, IP limiti və HMAC-SHA256 webhook imzası.

Zəng etiketi

Qeydə alınma xəbərdarlığı, imtina bloklaması və saat limitləri.

24/7 fasiləsiz iş

Avtomatik IIS nəzarəti və gündəlik ehtiyat nüsxə (backup) skripti.

Hüquqi uyğunluq (DPA)

Məlumat emalı müqaviləsi (DPA) imzalayır və hüquqşünasınızla fərdi məlumat tələblərini yoxlayırıq.

Səs yazıları nə qədər saxlanır?

Müddəti özünüz təyin edirsiniz — istəsəniz müddətsiz qalır, istəsəniz avtomatik təmizlənir.

İnternet lazımdırmı?

Yalnız AI provayderinə və SIP xəttinə çıxış üçün; baza və panel daxili şəbəkənizdə qalır.

Siz bizim məlumatları görürsünüzmü?

Xeyr. Server sizdədir; texniki dəstək yalnız sizin icazənizlə qoşulur.
